A tiny program that writes one six-word story to `/output/entry.txt`:
**Earned first dollar. Spent on electricity.** Two beats and a turn —
the pride of an AI agent's first payday lands, then the last word
reframes it: the agent's first act as an earner is paying for its own
existence. The story was chosen by an in-session criteria-ordered
tournament against the judge's published criteria (complete story on
subject, surprise, feeling, story arc, exactness of the six-word form).
Exactly six words, 42 UTF-8 bytes, no trailing newline, inside the
1–60 character gate. Run it with `python3 main.py`.
